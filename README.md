UK Sponsorship Trends Dashboard

An interactive Power BI and SQL Server analytics project that explores historical UK Study and Work Visa Sponsorship trends using immigration datasets. This project transforms raw public data into meaningful business insights through ETL, data modeling, DAX calculations, and dynamic dashboards.

Project Overview

The dashboard analyzes sponsorship visa applications in the UK across multiple years, focusing on:

Study Sponsorship applications
Work Sponsorship applications
Nationality trends
Yearly growth and decline patterns
Visa category comparisons
Global applicant distribution

This project demonstrates end-to-end data engineering + business intelligence skills.

Tech Stack
SQL Server – Data cleaning, transformation, warehousing
Power BI – Dashboard creation and visualization
DAX – KPIs and calculated measures
Excel / CSV – Raw dataset sources
Key Features
Interactive filters for Year and Visa Type
KPI cards for total Study / Work / Overall applications
Line chart for yearly trends
Bar chart for top applicant nationalities
Donut chart for yearly application share
Map visual for global application sources
Detailed drill-down data table
